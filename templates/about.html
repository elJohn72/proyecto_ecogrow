Proyecto

EcoGrow conecta sostenibilidad, datos y automatización en un mismo flujo.

Nuestra plataforma integra analítica de datos, persistencia robusta, telemetría IoT y una interfaz fluida para maximizar el rendimiento del sistema completo.

Enfoque tecnológico

Nuestra arquitectura modular garantiza escalabilidad extrema, combinando análisis en tiempo real con seguridad integral.

Infraestructura técnica

La plataforma utiliza una infraestructura en la nube de alto rendimiento con sensorización IoT de precisión para control ambiental.

Enfoque sostenible

La propuesta gira alrededor del cultivo hidropónico, la reutilización de materiales y el monitoreo eficiente de recursos.

Objetivos y alcance académico

EcoGrow nace como proyecto de grado orientado a demostrar cómo una torre hidropónica puede integrarse con software de gestión, persistencia en MySQL y dispositivos ESP32. El sistema permite registrar usuarios, vincular torres mediante códigos únicos, documentar cultivos por variedad y fase, y visualizar lecturas de sensores como pH, conductividad eléctrica, temperatura del agua y nivel del depósito.

La capa de control combina reglas de negocio, alertas y recomendaciones del módulo Agricultor IA para apoyar decisiones operativas sin reemplazar el criterio humano. Los administradores del proyecto pueden auditar usuarios y verificar el estado de la base de datos desde un panel restringido por correo autorizado.

Este sitio público presenta la propuesta; el panel de gestión requiere autenticación y está pensado para agricultores, tutores y equipos técnicos que monitorean el laboratorio o invernadero donde se instala cada torre.
