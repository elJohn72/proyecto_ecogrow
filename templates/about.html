Proyecto

EcoGrow conecta sostenibilidad, datos y automatización en un mismo flujo.

El proyecto nació como una práctica de Flask y hoy ya integra persistencia local, base relacional externa, telemetría IoT y una interfaz más clara para explicar el sistema completo.

Enfoque académico

Cada módulo responde a una semana distinta del proyecto: plantillas, CRUD, archivos, SQLite, MySQL y sensores.

Enfoque técnico

La plataforma usa Flask como núcleo, MySQL para datos relacionales y ESP32 con PlatformIO para sensorización.

Enfoque sostenible

La propuesta gira alrededor del cultivo hidropónico, la reutilización de materiales y el monitoreo eficiente de recursos.
