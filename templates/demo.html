Material de apoyo

Puedes incluir video, capturas, GIFs o una explicación paso a paso de la arquitectura.

Guion sugerido para la presentación

  1. Mostrar la landing y explicar el valor de monitoreo + gestión de cultivos.
  2. Crear o ingresar con una cuenta de demostración y registrar una torre de prueba.
  3. Asociar un cultivo activo y abrir el panel de sensores con datos de ejemplo.
  4. Opcional: enviar una lectura simulada vía API con token de dispositivo configurado.
  5. Cerrar con el módulo Agricultor IA y el reporte PDF de cultivos.

Si necesitas credenciales temporales o un entorno aislado, coordina con el equipo mediante la página de contacto.
